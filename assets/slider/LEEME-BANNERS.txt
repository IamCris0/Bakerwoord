BANNERS DEL SLIDER (pagina de Inicio)
=====================================

Se necesitan DOS versiones de cada banner: una horizontal para computadora
y una vertical para celular.

1) COMPUTADORA / TABLET  ->  1920 x 1080 px  (horizontal, 16:9)
   Nombre: 1.jpg, 2.jpg, 3.jpg ...

2) CELULAR  ->  1080 x 1350 px  (vertical, 4:5)
   Nombre: 1-movil.jpg, 2-movil.jpg, 3-movil.jpg ...
   (mismo numero que su version horizontal)

Formato: JPG.  Peso ideal: menos de 300 KB cada uno.


MUY IMPORTANTE AL DISENAR
-------------------------
La web escribe ENCIMA del banner el titulo, la descripcion y el boton.
No hay que dibujar texto dentro de la imagen.

  - En la version HORIZONTAL el texto va sobre el LADO IZQUIERDO.
    Deja ese tercio izquierdo despejado (fondo, sin producto importante)
    y pon la joya / el producto hacia la DERECHA o el centro.

    +------------------------------------------+
    |  (texto de la web)        [ producto ]   |
    |  deja libre                              |
    +------------------------------------------+

  - En la version VERTICAL el texto va al CENTRO, sobre la foto.
    Deja la zona central sin detalles finos.

    +----------------+
    |   producto     |
    | (texto encima) |
    |                |
    +----------------+

  - Fotos oscuras o de tono medio funcionan mejor: el texto es blanco.
    Si la foto es muy clara, el texto pierde legibilidad.


COMO CAMBIARLOS
---------------
1. Copia los archivos nuevos en esta carpeta (assets/slider/).
2. Avisame y yo los conecto en index.html.

Si algun banner no tiene version de celular, la web usa automaticamente
la horizontal: no se rompe nada, solo se recorta mas en el telefono.
